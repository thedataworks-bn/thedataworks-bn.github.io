EcoPulse AI & Sentiment Analyzer

M.Sc. Thesis — KSAWUV 2025–2026 Python · XGBoost · Scikit-learn · Flask
ML Framework for Household Carbon Footprint Analysis

Built a complete ML system on the Carbon Footprint Calculator Dataset to predict household Scope 1 and Scope 2 greenhouse gas emissions. Covers the full data science cycle — from raw dataset ingestion and feature engineering to benchmarking XGBoost Regressor against three other models, then deploying the best-performing model as an interactive Flask web app with an HTML/CSS frontend, real-time carbon footprint predictions and personalised energy-saving recommendations.

End-to-End Pipeline

Python 3.11 Scikit-learn XGBoost Pandas NumPy Matplotlib Joblib Flask HTML/CSS Google Colab VS Code
Model Comparison
XGBoost vs. Three Models
Trained XGBoost Regressor, Linear Regression, Decision Tree and Random Forest side-by-side on Scope 1 & 2 emissions data. Evaluated on MAE, RMSE and R² Score plus training time to select the best-performing model.
Emissions Tracking
Scope 1 & 2 Coverage
Dataset covers both direct household Scope 1 emissions (gas, fuel) and indirect Scope 2 emissions (grid electricity), giving a full view of household carbon footprint rather than just electricity use.
Web Deployment

NLP Internship Project

Instagram Comment Sentiment Analyzer

Python for AI Internship — MSc III Sem DistilBERT · RAG · Flask · Bootstrap
NLP Sentiment Analysis Web App Using DistilBERT & RAG

Built a full-stack NLP web application that takes a CSV file of Instagram comments, preprocesses the text with Pandas, and runs sentiment analysis using DistilBERT from Hugging Face Transformers. Implemented Retrieval-Augmented Generation (RAG) for context-aware understanding. The app classifies each comment as positive or negative and displays filtered, labelled results in the browser via a Flask backend with a Bootstrap frontend.

NLP Pipeline
CSV Upload› Text Preprocessing› RAG Context› DistilBERT Inference› Positive / Negative Classification› Filtered Results Display
Python DistilBERT Hugging Face Transformers RAG Pandas Flask Bootstrap HTML/CSS
LLM Inference
DistilBERT Sentiment
Used distilbert-base-uncased-finetuned-sst-2-english via Hugging Face Transformers to perform binary sentiment classification on Instagram comments — positive or negative — at scale from a CSV upload.
Retrieval-Augmented Generation
Context-Aware Understanding
Implemented RAG to give the model contextual grounding before inference, improving classification accuracy for ambiguous or slang-heavy social media comments.
Full-Stack Deployment
Flask + Bootstrap App
End-to-end Flask web app with a Bootstrap frontend. Users upload an Instagram comments CSV, the pipeline runs automatically, and results — labelled positive/negative with filtering — are shown in the browser.
